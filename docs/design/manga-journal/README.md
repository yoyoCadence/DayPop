# 漫畫手帳整頁主題（DP-218）

擁有者在 2026-10-28 明確委託整頁融合式主題、素材製作、程式整合、驗證及依既有流程發布。未指定風格，由 agent 依 DayPop 的手機日曆用途選擇深化既有「漫畫」，保留六套主題切換、已存偏好、四分頁、文字、使用者圖片及原月光貓。此為有意的視覺擴充，不宣稱是原稿復刻或擁有者另行目視驗收。

## 區域 → 素材 → 呈現方式

| 區域 | 素材 | 呈現方式 |
| --- | --- | --- |
| 桌面產品周圍 | desk／desk-dark | 兩份獨立淺深色漫畫工作桌；只在既有桌面預覽 media query 載入，中央保持安靜 |
| 手機與長內容邊緣 | page-edges | 手機專用直幅透明紙頁，限制於內容留白邊緣；不把桌面插圖縮成手機背景 |
| 日曆／搜尋／綜覽／設定頁首 | header | 透明墨線街景與紙邊，閱讀區局部遮罩；標題、導覽與按鈕保持原生 |
| 日期工作面、列表、卡片與 sheet | paper | 小幅白色纖維材質與原生墨線、紙邊陰影；保留日期狀態與行程原色 |
| 底部分頁 | navigation | 專用透明紅紙膠帶邊角，保留四個原圖示、文字與焦點；原生選取底線 |

## 設計規則

- 概念為 [concept.png](concept.png)，由真實原版日曆與長設定畫面生成完整日曆／設定／表單三態，再修正「只有外圍裝飾」的初版問題。概念內的生成字、假欄位與線稿貓不移入產品；原生文案、表單及既有 3D 貓優先。
- 原色票、Bangers／Noto Sans TC 字體配對、3px 輪廓、四分頁與 sheet 幾何沿用。新共享樣式只作用於 `data-theme="manga"`，其他五套主題不載入裝飾。
- 文字工作面維持中性白／炭黑，使用局部背景遮罩；不降低元件透明度、不改動原始圖片。不新增會攔截點擊或取得焦點的裝飾節點，也不新增動畫。
- 本機隔離遊客 QA，不登入正式帳號或覆寫正式資料。手機寬度模擬與實體手機分開記錄。

## 素材與提示詞

正式素材位於 `src/assets/themes/manga-journal/`；[prompts.json](prompts.json) 記錄 built-in image_gen 提示詞，[assets.json](assets.json) 記錄實際尺寸、bytes、來源及輸出 SHA-256、透明度。生成的原圖保留在 Codex generated_images；產品只引用已存入 repo 的 WebP，不依賴臨時網址。後處理只有縮放與 WebP 編碼，透明輸出保留 alpha。

## 驗證與對照

Chromium 實際介面已在 390×844 與 1280×900 檢查空／有行程、深淺色、搜尋結果、綜覽、長設定頁與原生新增表單。圖片逐張解碼，延遲圖片前後 header／月格／分頁 bounding box 不變；未見水平溢出。實際時區為 CLI 的 `Etc/GMT-8` 與回歸瀏覽器的 `Asia/Taipei`。Browser plugin 未提供，使用專案 Playwright 與官方 CLI；這是桌面與手機 viewport 模擬，沒有宣稱實體手機、螢幕閱讀器或新的雙帳號功能驗收。

最淡農曆字 `#646464` 在紙材質最低 RGB 228、35% 白色遮罩、6% 灰色斑馬底疊加後，保守底色 RGB 231.003，WCAG 相對亮度對比 **4.785:1**。深色 `#989898` 在最亮 RGB 255 紙材質、98% `#121212` 遮罩及同一斑馬底疊加後為 RGB 29.1756，對比 **5.832:1**。今天／選取日期仍用原不透明狀態底色；axe 沿原規則與最低可量文字門檻，沒有為本主題關掉背景或降低門檻。

六張 WebP 合計 **216,788 bytes**；手機四張合計 **59,712 bytes**（含會 inline 到共享 CSS 的 1,106 bytes 紙面），桌面僅另載當前模式的 90,564／66,512 bytes。Pillow 12.2.0 LANCZOS 縮放、WebP quality=82／method=6；透明素材 exact=True。最終本機 `npm run build -- --base=/DayPop/` 的 Pages 建置 CSS **119,236 raw／29,242 gzip bytes**、JS＋worker **747,193 raw／220,244 gzip bytes**，均在既有預算，未放寬守門；初版 117,539／29,175 的 CSS 數字屬於 root base，並非 Pages。發布 artifact 另逐 byte 核對，不用本機成品冒充公開成品。

新增整合回歸涵蓋延遲載入不移動、深淺色解碼、原生新增／搜尋／編輯／reload、損壞圖片仍保存、非漫畫重載不請求素材與原貓圖片保留。首次離線切換尚未快取的漫畫素材，會保留原生底色及字體 fallback，仍可保存、reload 讀回；只將精確的未快取素材／標題字體與離線版本檢查列為預期失敗。程式品質、完整單元及最終瀏覽器結果另見 tasks.md 的 DP-218；發布狀態以發布驗證文件為準。

素材載入只在使用者偏好就緒後啟用，避免 Auth 載入中的預設漫畫畫面讓其他主題多下載圖片。沒有改使用者 schema、偏好值、Auth、RLS、migration 或 service worker 快取權限。

PR #214 初次 CI `40797616595` 的三個 gate 成功，Chromium 完整結算為 291 passed／6 failed／13 skipped；六項家庭／分享短對話框因背景材質使 axe 可量文字不足而失敗，不能算通過。補上對話框標題、說明、清單及標籤的局部實底，保留周圍紙面，原六項在兩 viewport 重新通過；登入／公告配色及焦點另 14 passed／2 既有 skipped，本機假帳號分享確認的深淺畫面已目視。沒有降低最小量測數或排除背景。最終以修正後同 head 的四 CI 及完成審查為合併依據。
