# 開始使用翻月與背景提醒

適用於 0.4.7。先到「設定」確認目前版本；看到更新提示時選「立即更新」，再使用新功能。

## 切換月曆顯示

在「日曆」頁首點月曆圖示，開啟「月曆顯示方式」：

- **連續捲動**：上下滑動瀏覽連續月份。
- **單月翻頁**：每頁顯示一個完整月份，可左右滑動，或按前後月箭頭。

切換時會保留目前看到的月份；選擇保存在這台裝置，重新開啟 App 仍會沿用。設定中的「自動 4–6 列／固定 6 列」可另外選擇。

## 開啟背景提醒

1. iPhone 請使用加入主畫面後的日蹦 App，登入自己的帳號。
2. 到「設定 → 提醒」，開啟「這台裝置的通知」，並在系統詢問時允許。
3. 點要提醒的日曆，勾選「開啟這本日曆的提醒」，填寫提前分鐘後儲存。`0` 表示開始時；例如 `10, 30` 表示提前十分鐘及三十分鐘。
4. 全天事項另依設定的時刻與時區計算；有日期的未完成待辦需再勾選「同時提醒」。

每台裝置需自行開通知，每本日曆也需明確選擇。日曆規則會套用可讀的既有及未來事項；舊版每筆事項或預設提醒的數字不會自動開啟背景通知。分享日曆也不會替別人開啟通知。

可先將自己的測試日曆設定為 `0` 分鐘，建立約五分鐘後開始的指定時間行程，回主畫面或鎖屏等待。通知固定顯示「日蹦 DayPop／有日曆提醒，開啟日蹦查看。」，不顯示行程內容；點擊會開啟日蹦。排程、網路及系統通知設定可能造成延遲。

若狀態尚未確認，保持連線後按「重新確認提醒」並依畫面說明處理。暫時失敗會保留輸入；不要重複建立同一份事項。關閉裝置通知或登出會嘗試停用這台裝置，尚未確認完成時會持續顯示提示。
