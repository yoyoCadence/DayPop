# DayPop 夥伴素材授權與來源

本次依 DayPop 專案擁有者的製作委託新繪 SVG、在原生像素格繪製像素稿、建立 Blender 網格／材質／控制器。交接包的 ChatGPT 生成圖僅用於方向參考，未裁切、描圖、貼入、用作紋理或一併散布。各 manifest 保留對應參考圖的 SHA-256。沒有外部模型、貼圖、字體、商用素材庫或付費生成服務匯入角色成品。

編輯及產線工具為 Inkscape（GPL-2.0-or-later）、Blender（GPL-2.0-or-later）、Pillow（HPND）及 libwebp（BSD-3-Clause）。這些工具的程式碼與第三方資源未隨寵物圖輸出散布。此紀錄不代替專案擁有者的對外權利聲明，未為素材新增通用再散布授權，也未聲稱完成第三方商標／角色相似性清查。

製作紀錄由各角色原生來源、產物 manifest、SHA256SUMS 與 Git 提交對應。修改造型或動畫後需重新產出雜湊。
