# 兩個帳號開始使用共用行事曆

適用於已在 2026-10-26 發布的 **0.4.4「家庭日曆一起用」**：[開啟日蹦 DayPop](https://yoyocadence.github.io/DayPop/)。先到「設定 → 關於」確認版本；舊視窗可按「檢查更新 → 立即更新」，App 會重新載入新版。發布與資料保存驗證見 [本次紀錄](deployment-verification-2026-10-26.md)。

先用 A、B 兩個帳號試一個日曆。A 用一般視窗，B 用無痕視窗、另一個瀏覽器或另一台裝置，讓兩邊的登入狀態分開。各自以 Email＋密碼或 Google 登入；Email 註冊需先完成驗證信。登入後請確認畫面顯示預期帳號與「已同步」。

遊客資料與帳號資料分開保存，不會因登入而自動上傳。若已有遊客行程需要搬入帳號，先用既有 JSON 匯出／匯入預覽流程處理。

## 建立家庭與分享

1. **A 建立日曆。**「設定 → 日曆 → ＋ 新增日曆」，取容易辨識的名稱，例如「家庭共用」。
2. **A 建立家庭。**「設定 → 帳號與資料 → 管理家庭」，填群組名稱並建立。在「受邀 Email」填 B 實際登入且已驗證的 Email，按「產生邀請連結」。把連結交給 B；App 不會自動寄送家庭邀請信。
3. **B 接受邀請。** 用 B 的視窗開啟連結；需要時按「登入以查看邀請」，核對邀請資訊後按「接受邀請」。建立或接受家庭不會自動分享個人日曆。
4. **A 開啟日曆分享。**「設定 → 帳號與資料 → 設定日曆分享」，選「家庭共用」與「共同編輯」，按「下一步確認」，讀取包含歷史內容與編輯權限的說明後確認分享設定。
5. **B 載入分享。** 切回 App，或在同一區按「重新確認分享」。在「收到的日曆」看到「家庭共用」及「可共同編輯」後，就能開始使用。

每位日曆擁有者自行決定分享範圍；成為家庭管理員不會自動取得其他成員的私人日曆。

## 先用兩筆測試事項確認

| 操作 | 預期結果 |
| --- | --- |
| A 在「家庭共用」新增「A 測試行程」 | A 顯示已保存／已同步；B 重新確認分享後看得到 |
| B 編輯該行程，再新增一筆共用待辦 | A 切回 App 或重新確認分享後看得到修改與待辦 |
| A 在該日曆新增事項，勾選「不分享（只有日曆擁有者可見）」 | B 看不到這筆事項 |
| B 在自己的未分享日曆新增事項 | A 看不到 B 的個人事項 |
| A 把分享改為「只能查看」 | B 重新確認分享後只能閱讀，共同編輯操作不開放 |
| A 關閉分享 | B 重新確認分享後不再看到該日曆；舊表單不能繼續保存 |

新增行程或待辦時，留意「日曆」選的是「家庭共用」。私人事項的可見對象是**該日曆擁有者**；成員若要保存自己的私人安排，請選自己的個人日曆。

共享內容會在切回 App、恢復連線或按「重新確認分享」時更新。目前沒有即時推播同步；若另一邊暫時看不到修改，先確認已同步，再重新確認分享。兩人同時修改同一事項時，過期版本會被拒絕並保留草稿，重新核對最新內容後再提交。

收到的分享不放入裝置的帳號快取或個人備份，離線時會收起；附件、聯絡資料與貼圖仍由各自擁有者使用。個人備份包含自己擁有日曆的內容，包括成員在其中新增的事項；不包含收到的他人日曆。

若畫面顯示「尚未同步」或分享暫不可用，保留輸入內容，恢復連線後依畫面重新確認。登出再登入不會刪除雲端資料。
