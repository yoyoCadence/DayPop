# DayPop Sticker Phase 1 | 視覺規範 v0.1

狀態：**提案用 MVP，尚未定案／未整合 App**。先做四個視覺類型，目的是判斷是否有必要擴充至 24 張。

## 設計系統
- 原創漫畫貼紙風：統一墨線 `#261C22`、白色裁切邊、平塗，不使用漸層、文字、數字。
- 色彩：珊瑚粉 `#FF747A`、亮黃 `#FFD44F`、草綠 `#76BA79`、天空藍 `#72B8E8`、奶油 `#FFE6CA`、棕 `#80554D`。每張最多 3–4 個主要填色，黑白不計。
- SVG `viewBox=0 0 96 96`、透明背景、中心主體、不引用外部連結、不使用 JS/字型/點陣圖片。
- 黑線約 3–4.2 個 viewBox 單位；白色外輪廓約 8–9 單位。
- 真實大小依 DP-244：10、16、22 px；另提供 32/64 px 檢查結構。

## 四張代表樣本
1. `happy.svg`: 人物表情／mood／😊
2. `gift.svg`: 物品／celebrate／🎁
3. `cake.svg`: 食物／food／🍰
4. `hiking.svg`: 活動場景／travel／🏔️

**注意：** `fallback` emoji 是否確實存在 DP-243 `sticker-catalog.md`，尚未與該檔交叉驗證；整合前必須核對，不能視為已驗證資料。

## Phase 1 驗收
- 在 `preview.html` 用手機查看 100% CSS 縮放（10 px 和 16 px 的可讀性以手機實測為準）。
- 16 px 可識別情境；10 px 至少辨別形狀與主色。對不通過者修改 SVG，不是先放寬容量限制。
- 亮/暗背景白色裁切邊與墨線清楚；四張筆觸、顏色、比例一致。
- 實際部署 SVG 目標每張 <=4 KB，4 張均須檢查；完整 24 張上限 <=96 KB。
- 不動 App 的 `stickers` 表、不改 UI、不發布。
